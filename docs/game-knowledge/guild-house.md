# 公会之家

适用：国服雷电模拟器 960×540；2026-09-25 实测。

- 从底栏「公会之家」进入。首次进入时可能先显示「附加效果家具」的「等级提升完成」提示；关闭后可看到楼层与家具产物。
- 家具升级提示中的「无限点心桌」说明其产物包含体力，并显示生产间隔与保管上限；具体数值随家具等级变化，应以当前页面为准。
- 右下角「全部收取」会领取当前可收取的家具产物。收取回执逐项列出道具，其中可包含体力；关闭回执后应以顶栏体力数字变化确认到账。

- 回执可能只有扫荡券、经验药剂等，没有体力（2026-11-03 实测，距上次收取约 2.5 小时）。
- 没有产物时「全部收取」外观不变，点击后只短暂提示「没有未收取的道具。」，不弹回执，体力不变（2026-11-03 实测）。

尚未验证：其他分辨率的入口与弹窗布局。
